# Arts of Wood — Modern Website Package

Enhanced website for **Arts of Wood** (Kanke Road, Ranchi, Jharkhand).

## Features Included:
- **Responsive Architecture**: Works across phones, tablets, and desktop displays.
- **Dark / Light Mode**: Local-storage persisted theme toggle.
- **Interactive Project Cost Estimator**: Calculates real-time estimates for kitchens, wardrobes, living furniture, and aluminium partitions with a 1-click WhatsApp quote generator.
- **High-Definition Architecture Photography**: Preloaded CDN photography for kitchens, custom woodwork, and aluminium installations.
- **Interactive Portfolio & Lightbox**: Filter projects by category with full-screen view and keyboard controls.
- **FAQ Accordion**: Built-in answers to customer questions about workshop visits, factory pricing, and warranties.
- **Direct WhatsApp Lead Routing**: Connects inquiries straight to +91 93344 39854.

## How to run locally:
1. Extract the zip file.
2. Open `index.html` directly in any web browser (Chrome, Safari, Firefox, Edge).
